# Figuras e capturas de tela

Esta página pode ser usada para reunir imagens demonstrativas do artefato, sem aumentar o tamanho do README principal.

## Estrutura sugerida

Crie a pasta:

```text

```

Sugestão de nomes de arquivos:

